# Changelog

## 1.4.1
- Fixed: dropped items of the same kind but with different contents (e.g. a Potion of Swiftness and a Potion of Healing) are no longer merged into one line
- Fixed: the boat or minecart you ride is no longer counted
- Fixed: a display position edited by hand in the config file is kept on screen

## 1.4.0
- Settings moved to `config/KCMods/entitycounter/` - your old settings are moved there automatically
- After an update, a short "What's new" screen appears once

## 1.3.1
- The display stays visible with always-on debug entries like chunk borders (F3+F6); only the full F3 screen hides it
- The tour also appears on clients with their own main menu, like NoRisk
- The tour points to the settings

## 1.3.0
- Welcome tour on first start

## 1.2.0
- Move the display anywhere on screen by drag and drop
- Dropped items are listed by item name and stack size

## 1.1.0
- Green highlight on the counted block (can be turned off)
- Choose which block is counted: automatic, the block you look at, the one in front or behind
- Settings screen via Mod Menu
- Mod icon

## 1.0.0
- First release: press F7 to see which entities are in the block you look at, with picture, name and count
